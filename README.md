# Job Finder

A PHP and MySQL job board demo with a working job search backend, responsive landing page, authentication pages, and reusable UI sections.

## Features
- Custom sliders and toggles
- Stylish footers
- Working job search form with keyword and location filters
- MySQL-backed job results
- Responsive layouts
- Font Awesome icon support
- Multiple demo pages

## Usage
1. Clone or download this repository.
2. Import `database.sql` into MySQL.
3. Update `db.php` if your local database credentials differ.
4. Open `index.php` through your local PHP server.
5. Use the search form on the homepage to find jobs by keyword and location.

## Project Structure
- `index.php` – Main landing page and job search backend
- `login.php`, `register.php`, `logout.php` – Authentication pages
- `style.css` – Main stylesheet
- `database.sql` – Database schema and sample job data
- `font-awesome/` – Icon fonts
- `img/` – Image assets
- Other PHP files – Supporting pages
